# 横盘异动选股

A股横盘突破选股引擎，每天盘后自动扫描，手机微信接收信号。

## 策略逻辑

1. **横盘池**：全市场扫描，找出过去90个交易日处于横盘状态的股票，持续跟踪
2. **异动触发**：从池中筛选今日放量上涨的标的
   - 强信号：量比 ≥ 2.0 且 涨幅 ≥ 3%（微信推送）
   - 弱信号：量比 ≥ 1.6 且 涨幅 ≥ 2%（仅进报告）

## 筛选参数

| 参数 | 阈值 |
|---|---|
| 市值（流通） | 15亿 ~ 50亿 |
| 横盘周期 | 90个交易日 |
| 箱体振幅 | ≤ 30% |
| 均线粘合（5/10/20/60日） | ≤ 10% |
| 横盘期日均换手 | ≤ 3% |
| 收盘位置 | 箱体 50% 以上 |
| 剔除 | ST/*ST/退市风险/北交所/次新股/低价股(<3元) |

## 文件说明

| 文件 | 作用 |
|---|---|
| `scanner.py` | 选股引擎，产出 `result.json` |
| `report.py` | 生成 HTML 报告 + 微信推送 |
| `.github/workflows/scanner.yml` | 定时任务配置 |
| `pool.json` | 横盘池（自动生成，自动提交） |

## 定时

工作日北京时间 **18:30** 自动运行（UTC 10:30）。

## 部署要点

需在仓库 `Settings → Secrets and variables → Actions` 中添加：

- `SENDKEY`：Server酱 SendKey

## 注意

- 数据源：AkShare（新浪接口），免费
- 市值用 `流通股本 × 收盘价` 自算，不依赖东财
- 无强信号时不推送，节省 Server酱 免费额度（5条/天）
- 本工具仅提供信号参考，非投资建议
