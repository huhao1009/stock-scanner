# 黑牛稳健选股

A股每日盘后选股引擎，每个交易日自动扫描，手机微信接收信号。
当前策略为「黑牛稳健 v1」，经 1000 只主板样本回测验证（2022-08 ~ 2026-10）。

## 策略逻辑

```
信号 = EMA(C,5) 上穿 EMA(SLOPE(C,21)*20+C, 55)
过滤 = 改良KDJ J < 50          （不追高）
     + 收盘 < HHV(H,20)×0.94   （买回调）
     + 收阳（C > O）
     + 当日大盘涨家数 ≥ 50%
```

**回测结论**（未扣成本、有幸存者偏差，详见 bt_top3/）：

| 当日出票 | 次日胜率 | 20日均收益 |
|---|---|---|
| 1-6 只（稀疏日） | ≈基准，无超额 | ≈0 |
| 7-19 只 | 63.4% | +4.56% |
| 20 只以上 | 75.9% | +8.17% |

→ **价值集中在市场集体翻多的日子**，系统带密度门槛：出票不足
`max(7, 0.7%×有效扫描数)` 当天只记录、不推送。建议按「持有 20 个交易日、
均匀买一篮子」执行，回测证明同日信号内挑不出更好的个股。

休眠 ≤3 天（最近刚大动过）的信号标注「博连板候选」：连板概率约为其余的
4~6 倍，但整体收益不更好，属彩票性质，勿重仓。

## 代码结构（三件套，职责分开）

| 文件 | 管什么 | 换策略要改吗 |
|---|---|---|
| `strategy.py` | **选股逻辑**：信号定义、过滤、打分、文案 | ✅ **只改这个** |
| `scanner.py` | 数据管线：交易日判断、拉快照、并发抓日线、密度门槛 | ❌ |
| `report.py` | 通用报告渲染 + 微信推送 | ❌ |
| `selftest.py` | 离线自测：不联网造 K 线，验证逻辑和报告 | ❌ |

**核心约定**：`strategy.evaluate()` 返回什么字段，报告就显示什么。
加指标不需要改报告，换策略不需要动管线。详细契约见 `strategy.py` 顶部注释。

## 运行模式

| 环境变量 | 说明 |
|---|---|
| `SCAN_SCOPE` | `all`＝全市场扫描（默认）；`hot`＝只扫涨幅榜（省额度） |
| `WORKERS` | 并发线程数，默认 20 |
| `SCAN_LIMIT` | 只扫前 N 只，本地调试用 |
| `SENDKEY` | Server酱 SendKey（存在仓库 Secrets 里） |
| `REPORT_URL` | 报告网址，推送时附带 |

## 筛选参数

全部集中在 `strategy.py` 的 `CFG` 里。

| 参数 | 默认值 |
|---|---|
| 市值（流通） | 15亿 ~ 300亿（与回测口径一致） |
| 信号 | EMA5 上穿 EMA(SLOPE(C,21)*20+C,55) |
| J 上限 | 50（改良KDJ） |
| 买回调 | 收盘 < 20日最高价 × 0.94 |
| 大盘宽度 | 涨家数 ≥ 50% |
| 密度门槛（scanner） | max(7, 0.7%×有效扫描数) 达标才推送 |
| 持有建议 | 20 个交易日 |
| 剔除 | ST/*ST/退市风险/低价股(<3元) |

## 可交易范围（板块开关）

在 `strategy.py` 的 `UNIVERSE` 里，账户开不了的板块直接不扫：

| 板块 | 代码 | 门槛 | 默认 |
|---|---|---|---|
| 科创板 | 688/689 | 50万资金 + 2年经验 | 不扫 |
| 创业板 | 300/301/302 | 10万资金 + 2年经验 | 不扫（开了权限改 `exclude_cyb: False`） |
| 北交所 | 43/83/87/920 | 50万资金 | 不扫 |
| B股 | 900/200 | 美元/港币交易 | 不扫 |

剔除后实际扫描约 2500 只（沪/深主板，15~300亿），比全市场省约一半耗时和额度。

## 定时

每天北京时间 **18:30**（UTC 10:30）触发，周末和节假日由代码内部判断跳过。

## 注意

- 数据源：AkShare（新浪接口），免费
- 流通市值用 `流通股本 × 收盘价` 自算，不依赖东财
- 密度未达标 / 无信号时不推送，节省 Server酱 免费额度（5条/天）
- 扫描接口若被限流，会自动熔断并保留前一天的池子，不会把额度跑光
- 本工具仅提供信号参考，历史回测不代表未来收益，非投资建议
