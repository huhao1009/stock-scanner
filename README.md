# 横盘异动选股

A股横盘突破选股引擎，每个交易日盘后自动扫描，手机微信接收信号。

## 代码结构（三件套，职责分开）

| 文件 | 管什么 | 换策略要改吗 |
|---|---|---|
| `strategy.py` | **选股逻辑**：什么样的股票入选、什么算信号、怎么打分 | ✅ **只改这个** |
| `scanner.py` | 数据管线：交易日判断、拉快照、并发抓日线、维护横盘池 | ❌ |
| `report.py` | 通用报告渲染 + 微信推送 | ❌ |
| `selftest.py` | 离线自测：不联网造 K 线，验证逻辑和报告 | ❌ |

**核心约定**：`strategy.evaluate()` 返回什么字段，报告就显示什么。
加指标不需要改报告，换策略不需要动管线。详细契约见 `strategy.py` 顶部注释。

## 运行模式

| 环境变量 | 说明 |
|---|---|
| `SCAN_SCOPE` | `all`＝全市场扫描（默认）；`hot`＝只扫涨幅榜（省额度） |
| `WORKERS` | 并发线程数，默认 20 |
| `SCAN_LIMIT` | 只扫前 N 只，本地调试用 |
| `SENDKEY` | Server酱 SendKey（存在仓库 Secrets 里） |
| `REPORT_URL` | 报告网址，推送时附带 |

## 筛选参数

全部集中在 `strategy.py` 的 `CFG` 里。

| 参数 | 默认值 |
|---|---|
| 市值（流通） | 15亿 ~ 50亿 |
| 横盘周期 | 90 个交易日 |
| 箱体振幅 | ≤ 30% |
| 均线粘合（5/10/20/60日） | ≤ 10% |
| 横盘期日均换手 | ≤ 3% |
| 触发前提 | 收盘站上箱体 50% 位 |
| 强信号 | 量能 ≥ 2.0 倍 且 涨 ≥ 3%（推微信） |
| 弱信号 | 量能 ≥ 1.6 倍 且 涨 ≥ 2%（只进报告） |
| 剔除 | ST/*ST/退市风险/低价股(<3元)/次新股 |

## 可交易范围（板块开关）

在 `strategy.py` 的 `UNIVERSE` 里，账户开不了的板块直接不扫：

| 板块 | 代码 | 门槛 | 默认 |
|---|---|---|---|
| 科创板 | 688/689 | 50万资金 + 2年经验 | 不扫 |
| 创业板 | 300/301/302 | 10万资金 + 2年经验 | 不扫（开了权限改 `exclude_cyb: False`） |
| 北交所 | 43/83/87/920 | 50万资金 | 不扫 |
| B股 | 900/200 | 美元/港币交易 | 不扫 |

剔除后实际扫描约 3300 只（沪/深主板），比全市场省约四成耗时和额度。

## 本地自测

```bash
pip install pandas
python selftest.py        # 不联网，验证逻辑 + 生成 selftest_report.html
```

## 定时

每天北京时间 **18:30**（UTC 10:30）触发，周末和节假日由代码内部判断跳过。

## 注意

- 数据源：AkShare（新浪接口），免费
- 流通市值用 `流通股本 × 收盘价` 自算，不依赖东财
- 无强信号时不推送，节省 Server酱 免费额度（5条/天）
- 扫描接口若被限流，会自动熔断并保留前一天的池子，不会把额度跑光
- 本工具仅提供信号参考，非投资建议
